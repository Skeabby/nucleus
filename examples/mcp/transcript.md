# M4 — an agent drives a running Nucleus app

Generated by `node tools/mcp-demo.mjs`. The app is a real Notes server;
the MCP server is `packages/control-mcp`, talking to it over HTTP with the
bearer token from `run/apps.json`.

## 1. Handshake

```json
{
  "protocolVersion": "2025-06-18",
  "capabilities": {
    "tools": {}
  },
  "serverInfo": {
    "name": "nucleus-mcp",
    "version": "1.0.0"
  }
}
```

## 4. The command's schema

`nucleus_describe({ app: "nucleus.notes", command: "note.create" })` →

```json
{
  "name": "note.create",
  "title": "Create note",
  "description": "Create a new note and return its id.",
  "sideEffects": "write",
  "reversible": true,
  "params": {
    "type": "object",
    "properties": {
      "title": {
        "type": "string",
        "description": "Note title; defaults to \"Untitled\"."
      },
      "content": {
        "type": "string",
        "description": "Markdown body; defaults to empty."
      }
    }
  },
  "result": {
    "type": "object",
    "required": [
      "id"
    ],
    "properties": {
      "id": {
        "type": "string",
        "description": "Note node id."
      }
    }
  },
  "examples": [
    {
      "params": {
        "title": "Shopping",
        "content": "- [ ] oat milk"
      }
    }
  ],
  "mcp": {
    "expose": true,
    "name": "note_create"
  }
}
```

## 5. The agent proposes a write

Agents land in the review queue, not in the document:

```json
{
  "status": "proposed",
  "proposalId": "proposal-1",
  "command": "note.create",
  "touchedNodeIds": [
    "note-d41e6368"
  ]
}
```

## 6. The human accepts; the agent waits

`nucleus_wait` →

```json
{
  "app": "nucleus.notes",
  "proposal": {
    "id": "proposal-1",
    "status": "accepted",
    "command": "note.create",
    "actor": {
      "kind": "agent",
      "id": "opencode"
    },
    "label": "draft the demo note",
    "baseVersion": 0,
    "touchedNodeIds": [
      "note-d41e6368"
    ]
  }
}
```

## 8. …and it can be undone

```json
{
  "app": "nucleus.notes",
  "undone": true
}
```

Records after the undo (seq > 1):

```json
[]
```

---

Every mutation above went through the app's own `/api/op`: the proxy has no
private back door, and the actor on the tape is the MCP client, not the tool.
